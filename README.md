## 📖 Overview

Bloom & Petals is a visually engaging flower-shop interface built to practice **React component architecture**, **custom CSS styling**, **responsive layouts**, and **deployment with Vercel**.

It presents a floral retail experience with a modern homepage, product browsing concepts, shopping-oriented navigation, and contact UI. The focus is **frontend design and interactions**, rather than a fully operational store backend.

## ✨ Project Highlights

- **Floral-inspired homepage:** A strong hero section, flower imagery, and call-to-action elements
- **Shopping-oriented navigation:** Sections for shop, categories, testimonials, and contact
- **Product presentation:** Flower categories and featured item showcase concepts
- **React components:** Reusable UI patterns for a maintainable frontend
- **Custom CSS:** Personalized branding, layout, and responsive styling
- **Responsive design:** Interface designed to adapt across different screen sizes
- **Vercel deployment:** Experience publishing a frontend application

> **Scope clarification:** This is an eCommerce-inspired frontend project. Payment processing, real inventory management, a transactional checkout, authenticated customer accounts, and order fulfillment are **not verified** as implemented.

## ▶️ Run Locally

If the current repository includes the full React/Vite source:

```bash
git clone https://github.com/p-g-udara-dilshan/Bloom-and-Petals-REACT.git
cd Bloom-and-Petals-REACT
npm install
npm run dev
```

Open the local development URL displayed in the terminal. Confirm the exact Node.js requirements and available scripts in `package.json`.
